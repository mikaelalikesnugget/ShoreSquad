# ShoreSquad

## Overview
ShoreSquad is a web application designed to mobilize young people for beach cleanups. The platform provides users with tools to rally their crew, track weather conditions, and plan their next eco-action event with ease. By integrating social features and an interactive map, ShoreSquad makes environmental action fun and engaging.

## Features
- **Crew Rallying**: Easily invite friends and organize beach cleanup events.
- **Weather Tracking**: Access real-time weather data to plan your outings effectively.
- **Interactive Map**: Utilize a map interface to find and navigate to cleanup locations.
- **Social Connectivity**: Share your experiences and connect with other eco-warriors.

## Setup Instructions
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/ShoreSquad.git
   ```
2. Navigate to the project directory:
   ```
   cd ShoreSquad
   ```
3. Open the project in your preferred code editor.
4. Install any necessary dependencies (if applicable).
5. Launch the Live Server to view the application:
   ```
   Open index.html in your browser or use Live Server extension in VS Code.
   ```
